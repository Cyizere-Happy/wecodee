# Dashboard mascot guidance

The original WeCodee sheep reference is `public/posters/path-start.webp`. The dashboard illustrations use that character’s red headphones and varsity jacket, white hair, dark gloves and shorts, and red-and-white sneakers. Each illustration is a 512 × 512 transparent WebP. Interface text and diagrams are rendered in HTML.

The paths below are relative to `public/illustrations/mascot/`. `lib/workspace/mascot.ts` defines the available asset names and resolves them to URLs. The milestone guides match the standard SRS milestone name and order before displaying an example. The example across all eight milestones is a fictional community appointment app.
