# Dashboard mascot guidance

## Visual milestone lessons

The eight standard SRS milestones use native controls and diagrams built around a fictional clinic. Each interaction is local to the lesson. The clinic demonstrations use illustrative data, while milestone and operations panels read the workspace state.

The transparent 560 × 560 WebP assets below live in `public/illustrations/mascot/lessons/`. The scenes place the artwork on white alongside native HTML and SVG.

| Asset | Scene and composition |
| --- | --- |
| `srs-idea.webp` | Holds the resident’s request beside the interview excerpt |
| `srs-spec.webp` | Aligns a requirement strip with the structured document |
| `srs-interface.webp` | Presses an input beside the working reschedule demo |
| `observation.webp` | Inspects evidence as the learner switches from interview to booking log |
| `scope.webp` | Moves features along a release rail beside the scope comparison |
| `architecture.webp` | Attaches a cable beside the live request trace |
| `implementation.webp` | Connects a component between the code and the running form |
| `test.webp` | Points to two tokens competing for one slot in the testing example |
| `release.webp` | Pushes a software package through the gate beside the deployment pipeline |
| `presentation.webp` | Gestures toward the learner’s selected presentation slide |
| `review.webp` | Passes a document between trays beside the supervisor’s review paths |
| `publishing.webp` | Places a video tile in the library beside the draft-to-publish workflow |

The learner overview uses the state-specific guidance described below. The contribution and submission controls, feedback, checklist, and history are available via shortcuts on open milestones.

## Original dashboard illustration set

The original WeCodee sheep reference is `public/posters/path-start.webp`. The dashboard illustrations use that character’s red headphones and varsity jacket, white hair, dark gloves and shorts, and red-and-white sneakers. Each illustration is a 512 × 512 transparent WebP. Interface text and diagrams are rendered in HTML.

The paths below are relative to `public/illustrations/mascot/`. `lib/workspace/mascot.ts` defines the available asset names and resolves them to URLs. The milestone guides match the standard SRS milestone name and order before displaying an example. The example across all eight milestones is a fictional community appointment app.
